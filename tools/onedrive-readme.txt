نسخة كاملة من الموقع الشخصي – د. سيد مرعي
الموقع المنشور: https://sayednagy81.github.io

هذا المجلد يتحدث تلقائيًا (مهمة مجدولة على جهازك يوميًا وعند تسجيل الدخول) من نسخة الموقع على GitHub.
لا تعدّل الملفات هنا مباشرة؛ أي تعديل يُستبدل في المزامنة التالية. التعديل يكون على GitHub أو في C:\academic-site.

المحتويات:
- «المصدر - ملفات الموقع»: كل ملفات الموقع والإعدادات (البيانات، الأبحاث، نصوص الفيديو، التصميم، سكربت البناء، إعدادات النشر).
- «الموقع المنشور - نسخة كاملة»: الموقع جاهزًا كما يظهر على الإنترنت، يمكن فتح index.html منه.
- «سجل git الكامل.bundle»: كل تاريخ التعديلات في ملف واحد.
- «جميع روابط الموقع.html»: كل الروابط (الصفحات، الأبحاث، الفيديو، المقالات، الصفحات البحثية، لوحات الإدارة).
- «نسخ احتياطية»: نسخ مضغوطة قديمة وملفات مقالات.
- «سجل المزامنة.txt»: وقت ونتيجة كل مزامنة.

الاسترجاع الكامل عند الحاجة (على أي جهاز عليه git):
  git clone "سجل git الكامل.bundle" academic-site
ثم ربطه بالمستودع:  git remote set-url origin https://github.com/sayednagy81/sayednagy81.github.io.git

تشغيل المزامنة يدويًا:
  powershell -ExecutionPolicy Bypass -File C:\academic-site\tools\sync-onedrive.ps1
